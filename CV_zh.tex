\section{研究方向}

我当前的研究聚焦于面向新型 AI 芯片 LLM 基础设施的智能体。我参与原生多智能体 coding agent 系统研发，主要关注多智能体编排策略与工作流定制，并以程序化并发和 human-in-the-loop 工作流支撑长程系统研发；将这些方法用于演进抽象分层的算子优化 skill 系统与 agent 原生编译体系，由此提升模型服务效率，并将真实研发 trajectory 转化为增强 coding 与系统智能体能力的训练数据。

\ResearchStoryDiagram

\smallskip
\noindent \textbf{编译器与运行时底座。} 既有系统工作提供了智能体可操作的系统界面。\textit{IntelliC} (\ProjectLink{https://github.com/uv-xiao/IntelliC}{GitHub}) 研究面向人与智能体协作的可检查编译表示。\textit{PTO Runtime} (\ProjectLink{https://github.com/hw-native-sys/simpler}{GitHub}) 面向 Ascend 芯片和灵衢 SuperPod 执行编译后的任务图。\textit{Hive} (\ProjectLink{https://arxiv.org/abs/2604.17353}{preprint}) 将多智能体大模型负载暴露给推理基础设施，\textit{Spine} (\ProjectLink{https://github.com/arch-of-shadow/spine}{GitHub}) 研究跨设计意图、架构、编译器、硬件与执行证据的有界智能体协同设计。

\smallskip
\noindent \textbf{编译器驱动的敏捷芯片设计。} 我此前以编译器为组织架构定制与软硬件协同设计的核心。\textit{Hector} (\ProjectLink{https://doi.org/10.1145/3508352.3549370}{DOI}, \ProjectLink{https://github.com/pku-liang/Hector}{GitHub}) 提供面向硬件综合的多层次 IR；\textit{Cement} (\ProjectLink{https://doi.org/10.1145/3626202.3637561}{DOI}) 将周期确定的 CmtHDL 领域专用语言与具备时序分析、控制综合能力的 CmtC 编译栈结合；\textit{APS} (\ProjectLink{https://doi.org/10.1109/ICCAD66269.2025.11240817}{DOI}, \ProjectLink{https://github.com/pku-liang/APS}{GitHub}) 构建从架构 DSL 到硬件综合和软件编译的开源 MLIR 栈，\textit{Aquas} (\ProjectLink{https://arxiv.org/abs/2511.22267}{preprint}) 进一步加入面向领域的访存/综合指令与基于 e-graph 的可重定向编译器。\textit{Clay} (\ProjectLink{https://doi.org/10.1109/ICCAD66269.2025.11240669}{DOI})、\textit{Cayman} (\ProjectLink{https://doi.org/10.1109/DAC63849.2025.11132875}{DOI}) 与 \textit{SkyEgg} (\ProjectLink{https://arxiv.org/abs/2511.15323}{preprint}) 自动化微架构与加速器优化，\textit{ISAMORE} (\ProjectLink{https://doi.org/10.1145/3779212.3790162}{DOI}) 和 \textit{EggMind} (\ProjectLink{https://arxiv.org/abs/2604.17364}{preprint}) 则以形式化方法和大模型引导方法组织编译搜索。

\smallskip
\noindent 这条主线使用既有编译器与硬件系统作为基础，迈向下一步：让智能体帮助新芯片更好服务大模型，同时把生成的开发数据与 trajectory 反馈为更强 coding 与系统模型的训练材料。
